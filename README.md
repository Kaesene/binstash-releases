# Binstash — Instaladores

Repositório público com os instaladores compilados do **Binstash desktop**.
O código-fonte fica em [Kaesene/binstash-app](https://github.com/Kaesene/binstash-app) (privado).

## Última versão

Veja na aba [**Releases**](https://github.com/Kaesene/binstash-releases/releases/latest).

## Como instalar (Windows)

1. Baixa o `.exe` da release mais recente
2. Duplo-clique no arquivo baixado
3. Se aparecer aviso do SmartScreen: **More info → Run anyway** (só na primeira vez)
4. Segue o instalador (Next → Install → Finish)
5. Abre Binstash pelo menu Iniciar

## Como instalar (macOS — Apple Silicon)

1. Baixa o `.dmg` da release mais recente
2. Abre o `.dmg` e arrasta o **Binstash** pra pasta **Aplicativos**
3. Tenta abrir o Binstash. Vai aparecer um aviso de que **a Apple não pôde verificar** o app — é normal (o app não é notarizado). Como liberar (só na primeira vez):
   - **macOS 15 (Sequoia) ou mais novo:** vai em **Ajustes do Sistema → Privacidade e Segurança**, rola até o fim e clica em **"Abrir Mesmo Assim"** ao lado do aviso do Binstash. Confirma com Touch ID/senha.
   - **macOS 14 (Sonoma) ou mais antigo:** **botão direito** no app → **Abrir** → **Abrir**.
4. Abre o Binstash normalmente depois.

> O `.dmg` é para Macs **Apple Silicon** (M1/M2/M3…). Macs Intel não rodam este build.
